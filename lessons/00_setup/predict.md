# Predict, then run

Answer each question in a sentence before running `python lessons/00_setup/tour.py`.

1. Malaria's baseline rate in the generator is 40 cases per 100,000 per week, measles 0.8. Roughly
   how many times more malaria cases than measles cases do you expect over 12 weeks?
2. The cholera outbreak starts in week 7. Will it be visible in the national total, or only when
   you break the data down by district?
3. `population()` and `vaccinations()` take a `seed`. What happens if you call `population()` twice?
   What if you pass a different seed?
